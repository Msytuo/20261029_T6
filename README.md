
# Cuenta Atras

Este program es una simple cuenta atras, que tras varias condiciones consigues pararla o no. 

Tiene dos archivos un script.py y un archivo.txt.

Importante  que se están usando las bibliotecas "time" y "random"



## Instalar

Debes descargar el archivo de github y luego ejecutarlo con el siguiente comando:

```bash
  python .\countdown.py
```
